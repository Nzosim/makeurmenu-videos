# makeurmenu-videos

Vidéos courtes de MakeUrMenu, générées avec Remotion dans le cadre d'une automatisation IA.

Les vidéos sont ajoutées ici uniquement après validation sur Discord, puis envoyées automatiquement aux plateformes via Buffer.

Le dépôt sert d'hébergement public des fichiers `.mp4`, pour que Buffer puisse les télécharger.

## Structure

- `videos/` : une vidéo par dossier, nommée `AAAA-MM-JJ-sujet.mp4`.

## Licence
